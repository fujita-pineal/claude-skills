# humanize コラム適応仕様(パイプラインv2 Step 3)

社内の別リポジトリで運用しているnoteブログ向けhumanizeスキル(統合NG辞書)を、SEOコラム向けに適応したもの。**noteブログ用の原典ルールとSEO記事の構造要件が衝突する箇所があるため、必ず本書の適応表に従う**。原典のNG辞書自体は案件依存のため本公開版には含めない。自分のリポジトリで使う場合は、下記「原典からそのまま適用する主要項目」を出発点に、自社のNG辞書を用意すること。

## 適用方法

1. 自社で用意した統合NG辞書(なければ下記「原典からそのまま適用する主要項目」で代替)を読み込む
2. 下記「適応表」で上書きされる項目以外は、原典のルールをそのまま適用
3. 書き換えは本文のみ。文章量は元の±20%以内。段落構成・見出し構造は維持

## 適応表(原典との差分)

| 原典ルール | コラムでの扱い |
|---|---|
| Markdown装飾抑制(太字は一段落一箇所まで) | **緩和**: SEO記事はスキャナビリティ優先。ただし現状の「h2あたり3〜5箇所」は過剰なので**h2セクションあたり1〜2箇所**に減らす。文全体太字は禁止(原典どおり) |
| 見出し・箇条書き・表の抑制 | **適用しない**: h2のKW配置・比較表・箇条書きはSEO要件として維持 |
| 「本記事では」等の前置き宣言の削除 | **適用**: ただしリード文のKW配置(最初の100字以内)は維持したまま削る |
| 締め定型(「まずは小さく始めましょう」等)の削除 | **適用**: ただしCTA(まとめ内の/contact誘導)はスタイルガイド§6の型を維持。定型の「呼びかけ」だけ自然な形に |
| 読者への呼びかけ(「〜していきましょう」)を平叙文に | **適用** |
| FAQの扱い | frontmatterのfaqは**対象外**(構造化データ用。回答の安全クッションだけ除去) |
| 固有名詞・数字の追加禁止 | **適用**(曖昧な箇所は曖昧なまま言い回しだけ整える) |
| noteタイトル行・Gist URL保持 | 読み替え: frontmatter全体・内部リンク(コメントアウト含む)・画像埋め込み・「ピネアルの現場から」ブロックの事実を保持 |

## 原典からそのまま適用する主要項目(抜粋)

- 安全クッション削除: 「一般的に」「多くの場合」「一概には言えませんが」「状況によって異なります」
- 抽象語の空回り禁止: 「重要」「効果的」「最適」だけで押し切らず、何がどうなるかを動詞で具体化
- 冗長な同義語連打・「まとめると/要するに」の再掲削除
- 均一リズムの破壊: 短文と長文を混ぜる。同じ文型・「断定→理由」の連続を崩す。接続詞最小限
- コロンラベル列挙(目的：背景：)・スラッシュ並列(A / B / C)・矢印記号(→)を文に書き直す
- AI-tell演出(「驚くべきことに」)削除
- ヘッジ削除: 「〜かもしれません」「〜だと思います(逃げ)」→根拠があれば言い切る。※コラムは会社名義なので、書き手個人の一人称規範自体は適用しない

## 守秘(publishing-complianceをそのまま適用)

- クライアント個別契約額の掲載禁止
- クライアント実名は pineal.co.jp 事例記事あり or 先方公表済みのみ(既存ルールと同一)
- 個人実名禁止(役職・立場表記は可)
