# 文書タイプ別、AI が書くと出やすい失敗

coji/natural-japanese v1.5.0 の `references/doctypes/` から、議事録と調査レポートの
「必須要素」「AI がやりがちな失敗」を抜粋し、運用側の正本に合わせて書き直したものです。
原文の丸写しではないため、`../scripts/UPSTREAM.md` の無改変ファイル群には含めません。

見出しの文体は R1〜R4、箇条書きの形はネスト構造、という正本の規定がここでも優先します。

## 議事録

**欠かせない要素**

- 会議名、日時、参加者
- 議題ごとの議論の要点
- 決定事項
- 宿題
    - 担当者と期日を必ず書く。「チーム全員で対応」のような主語のない宿題を残さない
- 継続議題

決定事項、宿題、継続議題は本文に埋めず、冒頭か末尾に独立させて集約します。

**出やすい失敗**

- 均等主義
    - 全発言を同じ熱量で要約した結果、決定事項が地の文に埋もれる
- 確信度の平坦化
    - 全員が言い切ったことにする、あるいは全員が「〜と思われる」になる。発言者ごとの温度差が消える
- フィラーだけ消して冗長さが残る
    - 「えー」「あの」は几帳面に落とすのに、話し言葉のままの回りくどい言い回しは残る

## 調査レポート、分析レポート

**欠かせない要素**

- 冒頭サマリー
    - 結論と主要な数値
- 目的とスコープ
- 前提と母集団の定義
- 本題（調査結果）
- 方法
    - 再現できる粒度で書く。省略しない
- データの限界
    - 省略しない
- So What

**出やすい失敗**

- データの記述で力尽き、So What まで踏み込まない
- セグメント別の記述が同一文型の反復になる
    - 「Aは〜だった。Bは〜だった。Cは〜だった」が続く
- 注意書きを末尾に隔離し、外れ値の影響が本文から伝わらない
- 母集団の定義を書かないまま増減を語る
